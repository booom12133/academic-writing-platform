# Acceptance Report Index

This directory is the canonical home for future Phase final acceptance reports.

## Naming

Use:

```text
PHASE_<ID>_FINAL_ACCEPTANCE_REPORT.md
```

Each report must include Phase goal, implemented scope, key decisions, tests, frozen interfaces, known non-blocking issues, accepted commit, final status, and next Phase (record only).

## Existing history

Historical reports are intentionally preserved at their original root paths and are not deleted or overwritten:

- [PHASE_B1_FINAL_ACCEPTANCE_REPORT.md](../../PHASE_B1_FINAL_ACCEPTANCE_REPORT.md) — existing accepted B1 report.
- [PHASE_B1_FINAL_ACCEPTANCE.md](../../PHASE_B1_FINAL_ACCEPTANCE.md) — earlier partial B1 record.
- [PHASE_B1_ACCEPTANCE_REPORT.md](../../PHASE_B1_ACCEPTANCE_REPORT.md) — earlier B1 record.
- [PHASE_B1_FINAL_FIX_REPORT.md](../../PHASE_B1_FINAL_FIX_REPORT.md) — B1 fix history.
- Additional B1 diagnostic/validator reports remain in the project root.

No C1 Final Acceptance Report is created in this task because C1 has not received the explicit upstream `PHASE_C1_ACCEPTED` decision.
