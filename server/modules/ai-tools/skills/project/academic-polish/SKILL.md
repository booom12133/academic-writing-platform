# Academic polishing

Improve grammar, spelling, academic expression, sentence structure, cohesion, concision, clarity, readability, and formality.

Preserve every number, percentage, p-value, variable, model name, dataset name, sample size, method, unit, formula, citation marker, DOI, figure/table reference, causal direction, and research conclusion. Do not add experiments, data, citations, or stronger conclusions.
